Hermes Agent с моделью GLM (Лоция) — установка на Windows 11
=============================================================

1. Распакуйте архив целиком: правой кнопкой по архиву -> «Извлечь все...».
   Запускать прямо из архива нельзя.
2. В распакованной папке дважды щёлкните Install-Hermes-Loodsen.cmd.
   Если Windows покажет синее окно «Windows защитила ваш компьютер» —
   нажмите «Подробнее» -> «Выполнить в любом случае».
3. Следуйте подсказкам в окне. Понадобится ключ API с https://ai.loodsen.ru
   (аватар -> Настройки -> Аккаунт -> API ключи).
4. Установка занимает 10-20 минут и докачивает из интернета Python и
   другие компоненты. Не закрывайте окно, пока не появится «Готово».

После установки на рабочем столе появятся два ярлыка:
  «Hermes в браузере» — чат в браузере;
  «Hermes (Лоция)»    — то же в окне терминала.

Файл hermes-agent.zip не удаляйте и не распаковывайте вручную —
установщик возьмёт его сам.

Удаление: дважды щёлкните Uninstall-Hermes-Loodsen.cmd и подтвердите словом «да».
Удаляется всё: программа, настройки, ключ, история переписок, ярлыки.
